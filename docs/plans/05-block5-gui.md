# План: Блок 5 — GUI (PyQt5)

## Context
Блоки 0–4 готовы (`v2`, 94 теста). Блок 5 по `CLAUDE.md` — настольное приложение: загрузка картинки, выбор шума и метода с автоматически строящимися панелями параметров, три вкладки (изображения / визуализация / сравнение). Всё строится на реестрах из `core/registry.py` (`list_noises`, `list_denoisers`, `ParamSpec`) и `core/pipeline.py` (`apply_noise`, `run_denoiser`, `evaluate`) — GUI не знает про конкретные методы. Из v1 переносятся только `ZoomableImageView` и `SpectrumViewer` (`git show v1-legacy:src/denoise_app/ui/widgets.py`, прочитано).

**Важно по ресурсам:** сейчас в фоне идёт полный бенчмарк (`tune` → `run`). Он записывает в `results.csv` время работы методов, поэтому тяжёлые проверки на CPU (прогон всех методов в offscreen-тесте) во время фазы `run` исказили бы время. План: код пишется сразу, лёгкие проверки (ParamPanel, создание окна) — сразу, **полный offscreen-прогон всех методов — после того как `results/run.log` покажет «Добавлено строк» (проверяю `pgrep -af shumodav.bench`)**.

Первым действием при исполнении: скопировать этот план в `docs/plans/05-block5-gui.md`.

## Файлы (`src/shumodav/gui/`, плюс `run.py` в корне)

**`param_panel.py`** — `ParamPanel(QWidget)`; `ParamPanel(specs)`, метод `rebuild(specs)`.
- `QFormLayout`; по `ParamSpec.kind`: `float` → `QSlider` (0..1000, линейный или логарифмический при `log=True`) + `QDoubleSpinBox` (decimals из `step`, по умолчанию 2), оба синхронизируются; `int` → `QSpinBox` (min/max, `singleStep=step or 1`, для нечётных ядер шаг 2); `choice` → `QComboBox`; `bool` → `QCheckBox`. Если `min/max` нет — разумный запасной диапазон.
- `visible_if`: после любого изменения пересчитывается видимость строк (`QFormLayout.setRowVisible`).
- `changed = pyqtSignal(dict)` (значения: float/int/str/bool), `values() -> dict`, `set_values(dict)` (сигналы блокируются, один `changed` в конце).

**`widgets.py`** — перенос из v1:
- `ZoomableImageView` — почти как есть (зум колесом, кнопка «Сброс», `sync_state_from`); `set_image` принимает float [0,1] gray/RGB, делает `np.ascontiguousarray`; пустое состояние — подпись-заглушка.
- `SpectrumViewer` (matplotlib `FigureCanvasQTAgg`, импорт `backend_qtagg`; matplotlib разрешён только в `gui/`): `update_spectrum(image)` — лог-спектр, `show_image_directly(image, title)`, `show_message(text)` для «нет визуализации».

**`main_window.py`** — `MainWindow(QMainWindow)`:
- **Левая панель** (в `QScrollArea`): «Загрузить» / «Сохранить результат» (`core.io.load_image` / `save_image`); чекбокс «Работать в оттенках серого» (`core.io.to_gray`); группа «Шум»: `QComboBox` из `list_noises()`, `ParamPanel` по `params`, `QSpinBox` seed, чекбокс «Без шума (картинка уже шумная)»; группа «Метод»: `QComboBox`, сгруппированный по `family` (нескликабельные заголовки семейств + методы, `userData` = имя; только `list_denoisers()` — недоступные не показываются), `ParamPanel`, кнопка «Лучшие параметры»; блок метрик: PSNR/SSIM шумной и результата, время (при «Без шума» — «—»; `inf` → «∞»).
- Серые файлы, загруженные как RGB (все каналы равны), автоматически приводятся к 2D — чтобы не гонять 3 канала зря.
- **Обработка**: любое изменение (картинка, шум, seed, метод, параметры, режим серого) → `QTimer` single-shot 200 мс (debounce) и инкремент `latest_id`. Один активный `QThread` (`ProcessWorker`: шум → `run_denoiser` → `evaluate` → `denoiser.visualize(noisy, **params)` в try/except → сигнал `done(id, payload)`); если пока идёт расчёт настройки менялись — результат с устаревшим id **отбрасывается** и запускается новый. Исключения метода ловятся в воркере и показываются в статус-строке, окно не падает; шумная картинка при этом всё равно показывается. При закрытии окна — `wait()` на воркере.
- **Лучшие параметры**: читает `results/best_params.json` (путь из `bench.common.RESULTS`, JSON-ошибки игнорируются) при каждом обращении; ближайший уровень определяется по относительному расстоянию текущих параметров шума до `NoiseModel.levels`; кнопка неактивна, если файла или записи для (шум, метод) нет; `set_values` на панель метода.
- **Вкладки справа** (`QTabWidget`):
  1. «Изображения» — три `ZoomableImageView` (Оригинал / Шумное / Результат) с подписями, синхронный зум/прокрутка через `view_changed → sync_state_from`.
  2. «Визуализация» — лог-спектры трёх картинок + результат `denoiser.visualize()` (или «Для этого метода нет визуализации»). Рисуется только когда вкладка видима (matplotlib — только в UI-потоке, FFT больших картинок не тормозит остальное).
  3. «Сравнение» — кнопка «Прогнать все методы»; `CompareWorker` (QThread, тот же слот «один активный воркер», запрос ставится в очередь, если идёт обработка) прогоняет все доступные методы на текущей шумной картинке (параметры шума/seed берутся из снимка состояния) с лучшими параметрами из JSON или `default`; строки добавляются по мере готовности. `QTableWidget` (Метод, Семейство, PSNR, SSIM, Время, с), сортировка включена (элемент с числовым `__lt__` по `UserRole`); двойной клик → метод выбирается в комбобоксе и на панель ставятся параметры, с которыми он считался.
- Публичные методы для тестов: `load_path(path)`, `set_method(name)`, `set_noise(name)`, `compare_all()`, `is_busy()`.
- Статус-строка: «Обработка…», «Готово», «Ошибка метода: …»; все подписи по-русски, имена в коде по-английски.

**`app.py`** — `main()`: `import shumodav.denoisers` (регистрация), `QApplication`, `MainWindow().show()`, `exec_`; запуск `python -m shumodav.gui.app`.

**`run.py` (корень)** — тонкая обёртка `from shumodav.gui.app import main; main()` (с добавлением `src` в `sys.path`, если пакет не установлен). Старый `run.py` v1 удалён в Блоке 0, README на него уже ссылается.

## Тесты — `tests/test_gui_offscreen.py`
`pytest.importorskip("PyQt5")`, `os.environ["QT_QPA_PLATFORM"]="offscreen"` до создания `QApplication` (один на модуль), хелпер `wait_until(cond, timeout)` с `processEvents` и коротким `sleep`. Входная картинка — кроп `skimage.data.camera()` 96×96, сохранённый во временный PNG (без зависимости от `data/`).
- `ParamPanel`: float — слайдер и спинбокс синхронны, `values()` возвращают нужные типы; `visible_if` скрывает/показывает строки (`fft_lowpass.order` при смене `kind`; `drunet.sigma` при `auto_sigma`); `changed` испускается.
- Окно: создаётся, `load_path` → все три вида получили картинку; для **каждого** метода из комбобокса и нескольких шумов (`gaussian`, `salt_pepper`, `periodic`) после `set_method` дожидаемся результата — без ошибки в статусе, метрики заполнены; режим «Без шума» → метрики «—»; изменение параметров несколько раз подряд приводит к одному актуальному результату (проверка отбрасывания устаревших id).
- «Сравнение»: `compare_all()` → в таблице строк столько же, сколько доступных методов; двойной клик/метод `select_from_table(row)` меняет метод в комбобоксе.
- Тест полного прогона по всем методам помечен как «тяжёлый» (`@pytest.mark.slow`, маркер зарегистрировать в `pyproject.toml`), по умолчанию запускается, но я выполняю его вручную только после завершения фонового бенчмарка.
