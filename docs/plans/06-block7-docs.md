## Файлы

### 1. `README.md` (переписать, по-русски)
- Что это; скриншоты — `results/speed_vs_quality.png` / вкладки GUI не коммитим новыми файлами (лишнее), только ссылки на `results/`.
- **Установка:** Python ≥ 3.11 (<3.14), `poetry install`; опциональные группы `poetry install -E bm3d`; **CPU-torch отдельно:** `pip install torch --index-url https://download.pytorch.org/whl/cpu` (с оговоркой: `poetry install -E neural` может поставить CUDA-сборку); без torch/bm3d приложение работает, методы просто не появляются в списке.
- **Данные и веса:** `python scripts/get_data.py`, `python scripts/download_weights.py`; `custom_cnn.pth` уже в репозитории.
- **Запуск GUI:** `poetry run python -m shumodav.gui.app` / `python run.py`; кратко про вкладки; Wayland → `QT_QPA_PLATFORM=xcb`; предупреждение про тяжёлые методы на больших картинках.
- **Бенчмарк:** `tune [--quick]` → `run [--methods …] [--noises …] [--quick]` → `report`; что лежит в `results/`; резюмирование.
- **Обучение своей CNN:** ссылка на `docs/TRAINING_COLAB.md`, команда `python -m shumodav.nn.train --smoke`, план Б на CPU.
- **Структура проекта** (дерево из `CLAUDE.md`, актуализированное).
- **Как добавить новый метод** — пример ≈15 строк (класс `Denoiser` + `@register_denoiser` + `ParamSpec`, импорт в `denoisers/__init__.py`); пример проверяется отдельным тестом.
- Тесты: `poetry run pytest -q` (GUI-тесты — `QT_QPA_PLATFORM=offscreen`), лицензия KAIR (MIT, в `nn/kair/LICENSE`).

### 2. `docs/results.md` — выводы (по цифрам из `results/`)
Разделы по спецификации:
1. Лучший метод для каждого шума (из `best_by_noise.md` + по уровням из `summary_psnr.md`).
2. Где классика конкурирует с нейросетями (например, гауссов low/mid: BM3D vs DnCNN/DRUNet; спекл/Пуассон; соль-перец: медианный vs остальные) — разрыв в дБ по таблице.
3. Готовые DnCNN/DRUNet на негауссовом шуме против нашей CNN (в т. ч. соль-перец и периодический, где CNN не обучалась).
4. Режекторный фильтр на периодическом шуме (прирост относительно шумной и относительно остальных методов, по уровням).
5. Качество против скорости (`speed_vs_quality.png`, `best_by_noise.md`: быстрые методы < 0.05 с).
6. **Ограничения и честные оговорки:** серые кропы 256×256 Set12 (12 картинок), одна реализация шума на (картинка, уровень), параметры подбирались на 4 картинках BSD68, DnCNN/DRUNet обучены только на гауссовом шуме, `custom_cnn` — на смеси из 4 шумов (без периодического), время `run` могло слегка завыситься из-за параллельных GUI-тестов, на кривой обучения есть провал около 6000 итераций (по `train_curve.png`/`train_log.csv`).
Скрипт-извлекатель чисел остаётся во временной папке (не коммитим); в конце — автоматическая сверка каждого числа в тексте с CSV.

### 3. `docs/report_draft.md` — черновик разделов записки
- **Архитектура приложения:** слои (`core`/`denoisers`/`nn`/`bench`/`gui`), реестры и контракты (`ParamSpec`, `NoiseModel`, `Denoiser`), pipeline, потоки в GUI (debounce 200 мс, один воркер, отбрасывание устаревших id).
- **Методы** (кратко, с формулами): модели шума (гауссов, соль-перец, спекл `x+x·N(0,σ)`, Пуассона `Poisson(x·peak)/peak`, периодический `A·sin(2π f(x cosθ + y sinθ)+φ)`); mean/median/Gauss/bilateral/NLM/BM3D; FFT-фильтры — маски идеального, гауссова, **Баттерворта** `H = 1/(1+(D/D0)^{2n})`; режекция (пики спектра + `1−exp(−d²/2r²)`); вейвлеты — DWT/SWT, **soft-threshold** `sign(x)·max(|x|−T,0)`, **BayesShrink** `T = σ_n²/σ_x`, `σ_n = MAD(HH₁)/0.6745`, `σ_x = √max(σ_y²−σ_n²,0)`, YCrCb и усиленный порог цветности; нейросети — DnCNN/DRUNet, **residual learning** `x̂ = y − R(y)`, MSE, наша DnCNN-Lite (10 слоёв, 48 каналов, ≈170 тыс. параметров; параметры обучения — таблица из `TRAINING_COLAB.md`).
- **Методика эксперимента:** роли датасетов (train400 — обучение, BSD68 — валидация CNN и подбор параметров, Set12 — финальный тест), уровни шума, метрики PSNR/SSIM (формулы), seed = crc32, подбор по сетке (≤60 комбинаций), резюмирование, измерение времени (прогрев нейросетей).
- **Результаты:** ссылки на `results/summary_*.md`, `heatmap_*.png`, `gain_psnr.png`, `speed_vs_quality.png`, `examples/*.png`, `train_curve.png`, краткие цифры из `results.md`.
- **Выводы.**
Поля, которых нет в репозитории (время обучения на T4, номера рисунков/страниц) — помечаются `[вставить …]`.
